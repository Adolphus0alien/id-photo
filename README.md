# 证件照生成器

纯浏览器的证件照制作工具，人脸检测与抠图全部在本机完成，照片不会上传到任何服务器。

在线使用：https://adolphus0alien.github.io/id-photo/

## 功能

- 9 种规格：一寸、小一寸、大一寸、二寸、小二寸、大二寸、报名照 480×640、美签 600×600、自定义（毫米 + DPI），导出像素精确到 1px
- 上传后自动检测人脸，按标准套构图（头顶留白 10%、头部占比 68%），可用滑块、拖拽、滚轮微调
- 抠图换底：白、蓝、红、灰、渐变、原图、自定义取色；阈值与羽化可调，另有擦除/恢复修补画笔
- 导出 JPG/PNG 时写入 DPI，冲印按「实际尺寸」打印即为标准毫米数
- 排版打印：6 寸 12 张、5 寸 10 张、A4 64 张，带裁切线

## 本地运行

双击 `启动.command`（macOS），它会起一个只监听 127.0.0.1 的静态服务并打开浏览器。

不能直接双击 `index.html`：模型文件通过 `fetch` 加载，`file://` 协议下会被同源策略拦截。

## 技术

- [MediaPipe Solutions](https://google.github.io/mediapipe/) 的 `selfie_segmentation` 与 `face_detection`（Apache-2.0），模型运行文件放在 `vendor/`，通过 WebAssembly 在浏览器内推理
- 无构建步骤、无依赖，单文件 `index.html` 包含全部界面与逻辑

## 已知局限

深色头发压在深色背景上时，抠图会有残留块，这是 `selfie_segmentation` 模型能力上限。处理办法：先把「抠图阈值」从 50% 往上推，再用「修补画笔 → 擦除残留」直接涂抹，涂多了用「恢复人像」擦回。
